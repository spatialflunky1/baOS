# baOS
## Description
The BAsic Operating System (baOS) is an operating system built for simple tasks such as:
* Playing a video
* Listening to audio
* Or writing a file
## Note:
* When modifying the source tree run the command below so the editor knows where the inclusions are from
```
bear -- make
```
## Build Dependencies
- mtools
- xorriso
- OPTIONAL: qemu-system-x86_64
- OPTIONAL: bear
